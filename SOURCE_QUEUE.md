## Purpose

Prioritize which Joey Yap / Mastery Academy Qi Men sources should be researched next.

This file controls research order only.
Do not store Qi Men knowledge claims here.

## Priority Levels

### P0 — Core Primary Sources

Highest priority.

Use for sources likely to define the core reading system, structures, formations, timing, direction, destiny, or strategic execution.

Examples:

- Joey Yap Qi Men books
- Mastery Academy core Qi Men courses
- official training manuals/workbooks
- official long-form seminars

### P1 — Primary Application Sources

Direct Joey Yap / Mastery Academy sources focused on:

- business
- career
- negotiation
- investment
- strategic decision making
- timing
- execution
- case studies

### P2 — Partial Primary Sources

Allowed primary sources with incomplete access:

- official previews
- samples
- short official articles
- excerpts
- short videos
- partial transcripts

### P3 — Discovery Sources

Secondary or unverified material used only to discover primary sources.

Never use P3 as final evidence for Qi Men knowledge.

## Rules

1. Process P0 before P1 whenever possible.
2. Verify a source before extracting knowledge.
3. Do not extract from P3 sources.
4. If a source is paywalled or unavailable, mark BLOCKED instead of guessing its content.
5. When a source is completed, update its status instead of deleting it.
6. SOURCE_INDEX.md remains the authoritative source registry.
7. SOURCE_QUEUE.md only controls research priority and workflow.
